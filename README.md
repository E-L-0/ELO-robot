# ELO-robot
An expressive desktop robot built using ESP32 and C++.
## Features

- Animated eyes
- Smooth blinking
- Multiple emotions
- Idle animations
- RGB status lighting

## Hardware

- ESP32
- ILI9341 Display
- Breadboard
- Push Buttons
- RGB LEDs

## Software

- Arduino IDE
- C++
- TFT_eSPI
- Git

## Future Goals

- Voice Recognition
- Face Tracking
- AI Assistant
- Bluetooth
- Servo Neck
